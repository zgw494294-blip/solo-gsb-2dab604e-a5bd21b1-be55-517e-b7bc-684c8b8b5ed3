查询行程

站台分配（单站）

选择站点与站台数量（1～4），为经过该站的每次停靠分配站台。 可选预锁：按班次 ID 与从 0 起的停靠序号，把某次停靠锁定到指定站台。

单线区间冲突排查

选择当前时刻表中有直接相邻停靠的两个站点（任一方向），输入 0～30 分钟 清空间隔，检查该单线区间内各班次的占用冲突，并给出需暂缓调整的最少班次建议。 分析不修改时刻表。

车底接续规划

勾选当前时刻表中 1～60 个不重复班次并填写 1～120 分钟整备时间， 计算执行所选班次最少需要多少组可互换车底。仅当前班终站等于后班首站、 且后班发车不早于前班到达加整备时间时方可接续（不允许空驶，按完整日期计算）； 先最少化车底组数，再最小化接续等待总分钟数。分析不修改时刻表。

限座旅客疏运测算

选择起终站与时间窗（最早出发、最晚到达，按完整日期比较），勾选 1～60 个班次 并为每班填写 1～10000 的整数席位数（所选班次总停靠数不超过 300）。测算时间窗内最多可送达人数： 只使用所选班次，同一相邻停靠区段乘车人数不超过席位，下车后席位可复用；同车沿后续停靠前进无需换乘时间， 换车须满足本站换乘分钟数。可分多条行程送达；测算不写库。

区间延误传播排程

勾选当前时刻表中 1～40 个班次（所选班次总停靠数不超过 200），为需要晚点的班次 填写 0～120 分钟首发延误（未填按 0），并填写 0～30 分钟区间清空时间。相邻站点的无向站对视为 同一单线区间，区间内通过顺序按原定发车时间固定，前车到达加清空时间后后车才能发车；各班首发 不早于原时刻加指定延误，其余到发不早于原时刻，区间运行时长不变、站内停留不少于原定时长。 计算给出所有到发时刻逐项最早的可行排程与末到延误；计算不修改时刻表。 生成排程后可点击“查看归因”：对同一输入追踪每个晚点班次的末到根源 （起作用的首发延误、原时刻表本就违反清空间隔的区间冲突）及传导链。
